# Оплаты

Локальный веб-трекер подписок и регулярных платежей. **Проект в разработке.**

- Следующие списания, разовые и регулярные платежи, поиск и пауза подписок.
- План на 12 месяцев, средние расходы за месяц, годовые итоги и доли подписок по каждой валюте.
- Настройка сроков напоминаний и общего времени по Москве. Отметка об оплате переносит напоминания на следующий цикл.

## Как запустить

Скачайте исходники и откройте `index.html` в браузере. Для локальной разработки можно запустить `python -m http.server 8765 --bind 127.0.0.1` из папки репозитория и открыть `http://127.0.0.1:8765`.

Данные сохраняются в браузере. Отправка напоминаний по почте и в Telegram, а также синхронизация между ПК и телефоном пока в планах.
